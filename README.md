## 🚀 Projetos

**🐂 [Boi Gestor](https://github.com/JoaoGabrielRochaSilva/BoiGestor)**
Sistema web de gestão de rebanho bovino, desenvolvido em equipe na faculdade. Atuei principalmente no front-end: painel geral, cadastro e listagem de animais com filtros, controle de vacinação, relatórios com gráficos (Chart.js) e layout responsivo com menu para telas pequenas. O back-end usa Node.js, Express e MongoDB Atlas.
*Planejado, ainda não implementado: funcionalidades de genética, produtividade e IA.*
`JavaScript` `HTML` `CSS` `Chart.js` `Node.js` `Express` `MongoDB`

**🛒 [Sistema de Gestão de Loja](https://github.com/JoaoGabrielRochaSilva/LojaPOO)**
Projeto acadêmico de Programação Orientada a Objetos em Java: aplicação de console organizada em MVC, com classes DAO, persistência em MySQL via JDBC e relatórios em PDF com iText. Inclui produtos, estoque, carrinho, pedidos, cupons e entregas. README com instruções de instalação e execução.
`Java` `MySQL` `JDBC` `NetBeans`

**🌐 [Meu Portfólio](https://github.com/JoaoGabrielRochaSilva/MeuPortifolio)**
Site pessoal em HTML, CSS e JavaScript, criado para praticar estrutura de páginas, estilização e responsividade.
`HTML` `CSS` `JavaScript`
